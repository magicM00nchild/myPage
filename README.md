# myPage

**Persönliche Webseite**  
Erstellt mit [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/) und [Vite](https://vitejs.dev/).

## Features

- Moderne, responsive Oberfläche
- Social Media Cards mit Icons
- Mehrsprachige Startseite (Deutsch/Englisch)
- Übersichtliche Navigation

## Installation

1. Abhängigkeiten installieren
    ```bash
    npm install
   #oder 
    yarn install
    ```

2. Entwicklungsserver starten
    ```bash
    npm run dev
   #oder 
    yarn dev
    ```

## Verwendete Technologien

- React 19
- TypeScript
- Vite
- React Router
- React Icons

## Projektstruktur

- `src/components/` – Wiederverwendbare Komponenten (z.B. Card, Navbar)
- `src/pages/` – Seiten (Home, About, Contact, Impress)
- `src/assets/` – Bilder und statische Dateien
- `src/index.css` – Globales Styling
